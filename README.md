# رصد تبلیغات مزاحم و ناقض حریم خصوصی

این ریپازیتوری یک آرشیو عمومی و مستندسازی‌شده از روش‌های تبلیغاتی کسب‌وکارهایی است که توسط کاربران به‌عنوان اسپم، مزاحم، یا ناقض حریم خصوصی گزارش شده‌اند (مثل ارسال پیامک/ایمیل انبوه بدون رضایت، تماس‌های تبلیغاتی مکرر، ردیابی بدون اطلاع کاربر، فروش/اشتراک‌گذاری اطلاعات تماس و مواردی از این دست).

هدف این پروژه **افشای اتهام‌آمیز یا قضاوت حقوقی نیست**؛ هدف، گردآوری شواهد مستند و قابل‌بررسی است تا کاربران دیگر بتوانند تصمیم آگاهانه بگیرند و در صورت لزوم به نهادهای نظارتی (مثل سازمان حمایت از مصرف‌کننده) گزارش دهند.

## ⚠️ اصول پایه (حتماً بخوانید)

1. **این‌جا دادگاه نیست.** ما ادعا نمی‌کنیم فلان کسب‌وکار «مجرم» است؛ فقط می‌گوییم چه اتفاقی افتاده و مدرکش چیست.
2. **بدون مدرک، ورودی پذیرفته نمی‌شود.** هر گزارش باید با اسکرین‌شات یا مدرک قابل‌تأیید همراه باشد.
3. **حریم خصوصی افراد ثالث رعایت می‌شود.** شماره تلفن، ایمیل، یا اطلاعات شخصیِ خودِ گزارش‌دهنده یا افراد دیگر (غیر از کسب‌وکار تبلیغ‌کننده) باید قبل از انتشار سیاه (redact) شود.
4. **حق پاسخ محفوظ است.** اگر نماینده‌ی رسمی کسب‌وکاری بخواهد پاسخ یا توضیح بدهد، پاسخش به همان ورودی اضافه می‌شود (به بخش «فرآیند پاسخ» در CONTRIBUTING.md نگاه کنید).
5. اگر مدرکی جعلی یا گمراه‌کننده باشد، ورودی حذف و از مشارکت‌کننده گزارش عمومی می‌شود.

## ساختار ریپو

```
index.html              → صفحه اصلی سایت (GitHub Pages)
entries.json             → داده‌ی خام پرونده‌ها (نام، نوع تخلف، توضیح) که سایت از روی آن کارت می‌سازد
proof-manifest.json      → لیست خودکارِ پوشه‌های proof/ (اسم کسب‌وکار + مسیر + تعداد مدارک)، توسط اسکریپت ساخته می‌شود
scripts/scan-proof.js    → اسکریپتی که proof/ را اسکن و proof-manifest.json را می‌سازد
/entries/                → یک فایل مارک‌داون برای هر کسب‌وکار (توضیح + جدول شواهد)
/proof/<نام-کسب‌وکار>/    → اسکرین‌شات‌ها و مدارک خام مربوط به همان کسب‌وکار
CONTRIBUTING.md           → راهنمای کامل نحوه‌ی گزارش‌دهی و ارسال مدرک
```

## چطور مشارکت کنم؟

راهنمای کامل در فایل [`CONTRIBUTING.md`](./CONTRIBUTING.md) است. خلاصه‌اش:

1. یک Issue جدید با قالب «گزارش تبلیغ مزاحم» باز کن، یا مستقیم Pull Request بده.
2. اسکرین‌شات(ها) رو داخل `proof/<نام-کسب‌وکار>/` بذار (اطلاعات شخصی خودت رو محو/سیاه کن).
3. یک فایل توضیحی طبق قالب `entries/_template.md` بساز یا فایل موجود همان کسب‌وکار رو ویرایش کن.
4. تاریخ، کانال تبلیغ (پیامک/ایمیل/تماس/شبکه اجتماعی و...) و توضیح مختصر این‌که چرا این مورد رو اسپم یا نقض حریم خصوصی می‌دونی رو بنویس.

محتوای این ریپو مبتنی بر گزارش‌های کاربران است و نگهدارندگان پروژه صحت هر مورد را به‌صورت مستقل تضمین نمی‌کنند، هرچند تلاش می‌شود مدارک قبل از پذیرش بررسی شوند. اگر فکر می‌کنید ورودی مربوط به کسب‌وکار شما نادرست یا گمراه‌کننده است، از طریق Issue با ما تماس بگیرید.
